Project Structure
folder name: description
inputs: empirical networks from McLaughlin
data: outputs of simulation data 
empirical summaries: summaries of empirical networks with information on species richness
outputs: folder used to test how simulation outputs work/test simulation code ### note once analysis is finalized I plan to remove this folder and remain the the data folder 'outputs' or 'simulated_data'.
Simulations were run in MatLab. Analysis and visualization of simulated and empirical data were performed in RStudio.
